# Kittygram

Kittygram — социальная сеть для любителей котиков. Пользователи могут публиковать фотографии своих питомцев, указывать имя, год рождения, цвет и достижения кота, а также просматривать публикации других пользователей.

## Демонстрация

Развёрнутая версия проекта доступна по адресу:

**http://111.88.150.24:9000**

Административная панель Django:

**http://111.88.150.24:9000/admin/**


---

## Возможности проекта

- регистрация новых пользователей;
- авторизация и выход из аккаунта;
- создание публикаций о котах;
- загрузка фотографии кота;
- добавление имени, года рождения и цвета;
- выбор достижений кота;
- редактирование и удаление собственных публикаций;
- просмотр публикаций других пользователей;
- управление данными через Django Admin;
- работа REST API;
- запуск проекта в Docker-контейнерах;
- проксирование запросов через Nginx.
